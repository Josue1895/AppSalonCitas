# Agradecimientos

## Agradecimientos

### Agradecimientos

El desarrollo del proyecto AppSalonCitas representa el resultado de un proceso de aprendizaje, colaboración, investigación y aplicación de conocimientos en el área del desarrollo de software.

En primer lugar, agradecemos a nuestros docentes por la orientación, los conocimientos y el acompañamiento brindado durante el proceso de formación académica, los cuales fueron fundamentales para llevar adelante este proyecto.

También expresamos nuestro agradecimiento a los integrantes del equipo de desarrollo, quienes aportaron sus conocimientos, tiempo y esfuerzo en las diferentes etapas de construcción de la aplicación.

La colaboración permitió distribuir las responsabilidades relacionadas con el desarrollo frontend, backend y las pruebas del sistema, fortaleciendo el trabajo en equipo y la solución de problemas.

Agradecemos igualmente a las personas que brindaron recomendaciones, observaciones y apoyo durante el desarrollo y mejoramiento de la aplicación.

Finalmente, agradecemos a nuestras familias y a todas las personas que contribuyeron directa o indirectamente a la realización de este proyecto.

### Trabajo en equipo

AppSalonCitas fue desarrollado mediante un proceso de colaboración organizado por áreas de trabajo:

Analisis

* Desarrollo frontend.
* Desarrollo backend.
* Pruebas y verificación.
* Integración del proyecto.

La utilización de herramientas como Git y GitHub facilitó la organización del código y el seguimiento de los cambios realizados durante el desarrollo.

* Laravel.
* PHP.

Estas herramientas proporcionaron la base tecnológica necesaria para construir AppSalonCitas.
